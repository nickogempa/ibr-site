# Site IBR Sobral

```
index.html          estrutura (HTML semântico)
css/
  variables.css     cores, fontes, espaçamentos (edite aqui primeiro)
  base.css          reset, tipografia, utilitários
  layout.css        seções, container, grids
  components.css    nav, botões, cards, galeria, mapa, rodapé
  sections.css      hero, visão missionária, banner IBR Music
  animations.css    keyframes e revelação ao rolar
  responsive.css    ajustes para celular/tablet
js/
  menu.js           menu mobile
  reveal.js         animações ao rolar ([data-reveal])
  scroll-effects.js barra de progresso, header, parallax
  tilt.js           efeito 3D ([data-tilt])
  footer.js         ano do rodapé
img/                imagens do site
```

Animações no HTML: `data-reveal="up|left|right|zoom"` e `data-delay="1..4"`; efeito 3D: `data-tilt`.
